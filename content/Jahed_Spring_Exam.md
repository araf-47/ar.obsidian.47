# Mohammad Jahed Hasan Bhuiyan - Spring Boot Exam (Round-58)

1. Which of the following is correct syntax to exclude?
   - @SpringBootApplication(exclude =={Salary. class}) Public class Employee{}
   - @SpringBootApplication(include !={Salary. class})
   - @SpringBootApplication(exclude ={Salary. class}) Public class Employee{}
   - None
   **Correct Answer:** @SpringBootApplication(exclude ={Salary. class}) Public class Employee{}

2. The annotation to be added to automatically configure beans based on the classes added to the class path is ?
   - @AutoConfiguration
   - @EnableAutoConfiguration
   - @EnableConfiguration
   - None of the options
   **Correct Answer:** @EnableAutoConfiguration

3. What is the starting point of Spring Boot Application?
   - @Service
   - @Controller

4. How to configure hibernate in spring boot?

5. How to handle exceptions in Spring Boot?
