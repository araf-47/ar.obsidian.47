# Anik Hasan - Spring Boot Exam (Round-58)

1. What is the spring boot default embedded server?
   - Undertow Server
   - Tomcat Server
   - Glassfish Server
   - Jetty Server
   **Correct Answer:** Tomcat Server

2. Which of the following are Class level annotation?
   - @Controller
   - @Service
   - @Repository
   - All of the above
   **Correct Answer:** All of the above

3. Which of the following XML file is used by Maven?
   - Config.xml
   - META-INF.xml
   - Pom.xml
   - None of the Above
   **Correct Answer:** Pom.xml

4. What is the starter for using log4j2 for logging?
   - Spring-boot-starter-logger
   - Spring-boot-starter-log
   - Spring-boot-starter-log4j2
   - None of the options
   **Correct Answer:** Spring-boot-starter-log4j2

5. What is used for handling GET requests?
   - @GetMapping
   - @PutMapping
   - @PostMapping
   - None of the Above
   **Correct Answer:** @GetMapping

6. The annotation to be added to automatically configure beans based on the classes added to the class path is ?
   - @AutoConfiguration
   - @EnableAutoConfiguration
   - @EnableConfiguration
   - None of the options
   **Correct Answer:** @EnableAutoConfiguration

7. How we can disable a specific auto- configuration class?
   - Using include attribute of @DisableAutoConfiguration
   - Using not exclude attribute of @DisabaleAutoConfiguration
   - Using not include attribute of @EnableAutoConfiguration
   - Using exclude attribute of @EnableAutoConfiguration
   **Correct Answer:** Using exclude attribute of @EnableAutoConfiguration

8. What is the purpose of Rest Template ?
   - create applications that consume RESTful Web Services
   - create applications that produced RESTful Web Services
   - Both A & B
   - None
   **Correct Answer:** create applications that consume RESTful Web Services

9. Which of the following is correct syntax to exclude?
   - `@SpringBootApplication(exclude =={Salary. class}) Public class Employee{}`
   - @SpringBootApplication(include !={Salary. class})
   - @SpringBootApplication(exclude = {Salary. class}) Public class Employee{}
   - None
   **Correct Answer:** @SpringBootApplication(exclude ={Salary. class}) Public class Employee{}

10. What is the purpose of Spring Boot ?
   - MVC Framework
   - Java Framework
   - Web Development Framework
   - All of the Above
   **Correct Answer:** All of the Above

11. How could you secure MVC controller with Spring Security?
   - With the @Secured annotation
   - With the @RolesAllowed annotation
   - In a XML security configuration file
   - All of the above
   **Correct Answer:** All of the above

12. What is the starting point of Spring Boot Application?
   - @Service
   - @Controller
   - @SpringBootApplication
   - None of the Above
   **Correct Answer:** @SpringBootApplication

13. Which of the following annotation used for Restful Web Services?
   - @Controller
   - @SpringBootApplication
   - @RestController
   - All of the Above
   **Correct Answer:** @RestController

14. How to configure hibernate in spring boot?
   - h2
   - spring-boot-starter-data-jpa
   - Both a & b
   - None of the above
   **Correct Answer:** spring-boot-starter-data-jpa

15. How to disable the default web server in the Spring Boot application?
   - spring.main.web-server-type=none
   - spring.main.web-application-type=none
   - spring.main.application-type=no
   - spring.web-application-type=no-server
   **Correct Answer:** spring.main.web-application-type=none

16. Which of the following annotation is used to bind application properties to the class fields?
   - @ApplicationProperties
   - @ConfigurationProperties
   - @AppProperties
   - None of the above
   **Correct Answer:** @ConfigurationProperties

17. Springboot enables the developers to use?
   - Multiple Annotations
   - Single Annotation
   - Both
   - None
   **Correct Answer:** Both

18. What is the default method of @RequestMapping?
   - Pull
   - Patch
   - Post
   - Get
   **Correct Answer:** Get

19. Do you think Spring Boot upgrades all dependencies automatically?
   - True
   - False
   **Correct Answer:** False

20. Which you needed to build a RESTful Web Services?
   - Spring-boot-starter-rest
   - Spring-boot-starter-web.rest
   - Spring-boot-starter-web
   - None
   **Correct Answer:** Spring-boot-starter-web

21. Which of the following are embedded containers supported by Spring?
   - Undertow
   - Tomcat
   - Jetty
   - All of the above
   **Correct Answer:** All of the above

22. Which Maven command is used to run a Spring boot application ?
   - maven spring-boot:run
   - Mvn spring: run
   - mvn spring-boot:run
   - None of the options
   **Correct Answer:** mvn spring-boot:run

23. Which of the following is not a spring boot layer?
   - Presentation Layer
   - Service layer
   - Persistence Layer
   - Business Layer
   **Correct Answer:** Business Layer

24. How to handle exceptions in Spring Boot?
   - @Advice
   - @ControllerAdvice
   - @SpringBootException
   - @ExceptionHandler
   **Correct Answer:** @ControllerAdvice

25. How primary key is annotated with attribute?
   - @Column
   - @Id
   - @PrimaryKeyNotNull
   - @PrimaryKeyNotNullAutoIncrement
   **Correct Answer:** @Id
